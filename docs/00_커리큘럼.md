# Nexacro N 강의 커리큘럼 — HR Admin 실습 프로젝트

초급 4단계 + 중급 5단계, 총 9단계.
각 단계는 「이론 → 따라하기 실습 → 과제」 구성을 권장하며, 1단계 ≈ 강의 1~2차시 분량입니다.

---

## 초급

### 01. 로그인 화면 — Nexacro 첫걸음
- **학습 목표**: Nexacro Studio 사용법, Form의 구조(.xfdl), 기본 컴포넌트와 이벤트 모델 이해
- **이론**
  - Nexacro 플랫폼 개요(원소스 멀티유즈, 화면 = XML + JavaScript)
  - Nexacro Studio 화면 구성(디자인/스크립트 뷰, 속성창, Invisible Object)
  - 컴포넌트: Static, Edit, Button / 이벤트: onclick, onkeyup, onload
- **실습**: 로그인 화면 작성 — 아이디/비밀번호 입력, 빈값 검증, 로그인 버튼/Enter 키 처리
- **과제**: "비밀번호 표시" CheckBox 추가 (password 속성 동적 변경)

### 02. 사원 목록 — Dataset과 Grid
- **학습 목표**: Nexacro 데이터 처리의 중심인 Dataset 개념과 Grid 바인딩 이해
- **이론**
  - Dataset 구조(ColumnInfo/Rows), Invisible Object의 개념
  - Grid-Dataset 바인딩(binddataset), Grid Contents 편집(head/body)
  - Dataset 주요 메서드: getColumn, setColumn, rowposition
- **실습**: 사원 목록 화면 — Dataset에 초기 데이터 입력, Grid 바인딩, 행 선택 시 하단 상세 표시
- **과제**: 검색 조건(사원명 Edit)으로 Dataset filter 적용

### 03. 사원 등록/수정 — 바인딩과 검증
- **학습 목표**: 컴포넌트-Dataset 바인딩(bind item)과 입력 폼 패턴, 데이터 검증
- **이론**
  - bind item(컴포넌트 ↔ Dataset 컬럼 양방향 바인딩)
  - Combo/Calendar/MaskEdit 컴포넌트, innerdataset
  - Dataset 행 추가/삭제(addRow, deleteRow), 변경 상태(getRowType)
- **실습**: 사원 등록/수정 화면 — 신규/수정 모드, 필수값·형식 검증, 저장(로컬 Dataset 반영)
- **과제**: 삭제 기능 + 삭제 전 confirm 처리

### 04. 부서-사원 마스터/디테일 — Dataset 관계
- **학습 목표**: 두 Dataset 간 연동(마스터/디테일) 화면 패턴 습득
- **이론**
  - onrowposchanged 이벤트, Dataset filter vs 조회 분리 전략
  - Div 컴포넌트로 화면 분할, 레이아웃(좌: 부서 트리/그리드, 우: 사원 목록)
- **실습**: 부서 선택 → 해당 부서 사원만 표시, 사원 더블클릭 → 상세 폼 연동
- **과제**: 부서별 사원 수를 마스터 Grid에 expr(수식 컬럼)로 표시

## 중급

### 05. 서버 연동 — transaction
- **학습 목표**: Nexacro 표준 통신(transaction)과 XML 서비스 데이터 구조 이해
- **이론**
  - transaction() 6개 인자(서비스ID, URL, 입력/출력 Dataset, 인자, 콜백)
  - Nexacro 표준 XML 포맷(PlatformXml: Parameters/Dataset), ErrorCode 처리
  - 환경설정: typedefinition의 Services(prefixid) 등록
- **실습**: 2~4단계의 하드코딩 데이터를 `data/*.xml` 정적 파일 조회로 전환, 공통 콜백 작성
- **과제**: 조회 조건을 인자(argument)로 전달하는 구조 설계(정적 파일 한계 토론 포함)

### 06. MDI 프레임 — 업무 시스템의 뼈대
- **학습 목표**: 실무형 프레임 구조(상단 메뉴 + 좌측 메뉴 + 멀티탭 작업영역) 구성
- **이론**
  - ADL(app.xadl)과 FrameSet/ChildFrame, Form 간 이동
  - 메뉴 Dataset 기반 동적 메뉴, 탭 방식 화면 오픈/중복 방지
- **실습**: 로그인 → 메인 프레임 진입, 메뉴 클릭으로 사원/부서 화면을 탭으로 오픈
- **과제**: 열린 탭 닫기(전체 닫기 포함) 기능

### 07. 공통 팝업 — 화면 간 데이터 전달
- **학습 목표**: 모달 팝업 호출과 부모-자식 화면 간 파라미터 전달 패턴
- **이론**
  - getOwnerFrame().form, openPopup/showModal, 팝업 → 부모 값 반환(close 반환값/콜백)
- **실습**: 사원검색 공통 팝업 — 어느 화면에서든 호출, 선택값을 호출 화면에 반환
- **과제**: 우편번호 검색 팝업 추가(주소 Dataset 기반)

### 08. 공통모듈 — 코드 재사용
- **학습 목표**: 실무 필수인 공통 함수 라이브러리 구조 이해
- **이론**
  - .xjs 스크립트 모듈과 include, 공통 메시지/검증/유틸 함수 설계
  - 공통코드 Dataset을 Combo에 일괄 세팅하는 패턴
- **실습**: gfn_alert/gfn_confirm, gfn_isNull 등 공통 함수 작성 후 기존 화면 리팩토링
- **과제**: 필수입력 일괄 검증 함수 gfn_validate (컴포넌트 목록 인자)

### 09. 마무리 — 실무 기능
- **학습 목표**: 운영 시스템에서 자주 요구되는 부가 기능 구현
- **이론**
  - ExcelExportObject 사용법, 다국어 처리(환경변수/리소스 전략)
- **실습**: 사원 목록 엑셀 내보내기, 한/영 전환 버튼
- **과제(종합)**: 휴가신청 화면을 처음부터 끝까지(목록-등록-팝업-공통모듈 적용) 스스로 작성
